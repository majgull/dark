# History

dark began as a private research project, opened in 2026. The question was
whether a language model could write code on its own, inside a machine that
exists for one task and is deleted when the task ends, judged by tests it
never sees. dark is the machinery that ran that study.

The study is [dark-paper](https://github.com/majgull/dark-paper), which pins
this repository at tag `v0.1.0`. The task set the study used is
[dark-tasks](https://github.com/majgull/dark-tasks).

The runner and the bench were developed on a private Git server and imported
here at the commits the paper names. Private identifiers (network addresses,
account names, and the names of private repositories and tools) were replaced
by role names or generic words before import; nothing else changed.
