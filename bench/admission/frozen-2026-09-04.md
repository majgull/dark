The *admission table* is the runner's answer to "which model tiers may take
a run of this class". It is derived from the ledger, so it moves as runs
land. L2's local lane compares two rounds of the same configuration, which
only means something if the table did not move between them (950 gaps, G6),
so this file is the table as it stood when L2 started and the two rounds
name this file.

Read as printed by `python3 -m dark admission` on the runner host: a `*`
marks an admitted tier, `basis` is `measured` (enough passes at the class's
thinking level), `provisional` (admitted while it has too few) or
`excluded`, `rate` is the pass rate over runs at that level and `n` the
number of runs behind it.

runner commit 7d84b44 (2026-09-04), so the test version behind every `n`
below is NOT MEASURED. Rows counted from runs after that commit carry
